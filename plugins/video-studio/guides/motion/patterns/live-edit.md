# Pattern: live edit

A control and the thing it controls share the frame, and every edit changes both in the same moment: a value scrubbed
and the element turning, a size retyped and the preview resizing, a hover and the readout updating. 5–12 s.

**Beats**
0. *Optional title card* naming the ability, then a cut or a fast pull-back to the stage.
1. *The pair is established:* the surface with its panel docked or sliding in; selection marks show which element is
   bound; the cursor glides to the first control.
2. *Edit beats* (about 2 s each), each one continuous manipulation and its live answer: drag a number, drag a handle
   along a path, retype a value; or select the element and watch the panel fill; or pick a unit and watch the readout
   convert.
3. *It proves out:* the last edit holds; or a big pull-back shows the finished product doing the edited thing; or a
   callout points at the result.

**Keep:** both halves always in frame together: the camera holds wide, makes one slow move, or pushes in and returns
to exactly the opening framing, never cropping the mirrored half out.

**Techniques:** control scrubs, synced counters, presses (`../techniques/cursor.md`, `../techniques/data.md`).
