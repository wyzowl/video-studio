# Pattern: mark to button

The brand's mark, resting in the centre, condenses into a smaller, brighter button in the same place, and a cursor
arrives and clicks it. The eye is walked from "who we are" to "what you do". 4–6 s.

**Beats**
1. *Presence (to about 1.4 s):* the mark holds dead centre; any line under it stays perfectly still.
2. *The morph (about 1.4–2.4 s):* the mark shrinks and fades exactly as the button grows in its place, both scaling
   from one shared origin, so it reads as one thing transforming.
3. *Approach:* the cursor arrives from off the frame on a decelerating path and lands a few pixels off the button's
   centre, so the aim reads as human.
4. *Press:* cursor and button compress together, then release, with a ripple or a glow. Hold on the pressed state.

**As an opener:** a lone widget (a pill, a chip) on a plain field is clicked, transforms in place (expanding into a
menu, springing out into a card), does its one thing (text typing, a colour flipping to active), then vanishes, and
a title types on the empty frame.

**Keep:** the camera still: a camera move would compete with the click.

**Techniques:** same-centre morphs, presses, click ripples (`../techniques/layout.md`, `../techniques/cursor.md`).
