# Pattern: cursor demo

A visible cursor drives the product's real interface through clicks, hovers and drags, so the screen changes state
from beat to beat. The product is the subject and the cursor the actor. 4–13 s.

**Beats**
1. *The surface and the first touch:* the interface is there (or flies in and settles); the cursor enters and does
   the first thing, and the interface answers in the same beat.
2. *The engine:* each next interaction, connected either by the camera following the cursor (a push and pan, a
   whip, a pan down) or, on a locked frame, by the interface itself moving (a dialog springing up, a panel sliding in,
   a table filling, a list filtering as letters are typed).
3. *The payoff:* the cursor lands on the main action or the result appears, and the frame holds.

**Shapes**
- **First look:** light and exploratory: hovers and highlights that show the surface exists.
- **A workflow:** two to four real edits the interface answers, ending on the action button or the result.
- **A locked tour:** the camera never moves; every change is a click-triggered element.
- **Drag and drop:** one continuous shot: a chip dragged as a ghost onto a page, snapping into place, then adjusted.
- **Inspecting:** a panel following the cursor across elements, outlining each.
- **Many hands:** several labelled cursors working a canvas at once while a headline builds over it.

**Keep:** the cursor big enough to follow (4–7% of the frame), entering from off-screen; each click causes the next
thing on the same frame; real screens from the product (`../../design/brand.md`, "Real assets").

**Techniques:** cursor moves, click ripples, presses, camera tracking (`../techniques/cursor.md`,
`../techniques/camera.md`).
