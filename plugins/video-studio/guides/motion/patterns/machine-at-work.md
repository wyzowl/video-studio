# Pattern: the machine at work

One trigger hands the frame to the product, which visibly works (spinners, status words, counters), then the receipt
arrives as rows that change state in front of the viewer. 4–11.5 s.

**Beats**
1. *The trigger (to about 1.5 s),* one beat: a menu opens and one option is clicked; a dialog's button is pressed;
   or the work is already running. The cursor appears here only.
2. *The working state:* nothing is clickable; chain one to three motifs: a spinner beside a label typing itself, status
   pairs swapping at a steady pace, a tool label docking to a corner, a heading changing tense as rows land.
3. *The receipt:* a card springs open and rows cascade in, then change: numbered badges flip one by one to ticks,
   labels strike through and dim; or a conversation builds message by message.
4. *Resolve:* hold the card (even part-way through its list, so the work reads as ongoing), or one push onto the
   confirmation line.

**Keep:** one colour reserved for the machine working and one for done; the working loops are the story here, so
they're allowed, but each is finite and stops on the exact frame the state resolves; at most one camera move.

**Techniques:** status swaps, ticks drawing, strike-throughs, counters (`../techniques/text.md`,
`../techniques/data.md`).
